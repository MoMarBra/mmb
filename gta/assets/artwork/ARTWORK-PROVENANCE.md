# Mission completion artwork provenance

Created 2026-09-15 for the local BBE Munich Consulting Simulator project.

The finished static title graphics `mission-passed.svg` and `respect-plus.svg` were rendered locally using Pricedown Black 5.200, designed by Ray Larabie / Typodermic Fonts Inc. Each SVG contains one complete, outlined composition with transparent background. They contain no font file, character addressing, reusable glyph library, font CSS, scripts, or runtime-generated lettering.

- Font page: https://typodermicfonts.com/pricedown/
- Authorized download page: https://typodermicfonts.com/desktop/

- License guidance: https://typodermicfonts.com/license/
- Included exact agreement: Typodermic Desktop EULA v260817, effective August 17, 2026, saved as `desktop/Typodermic Desktop EULA 2026.pdf`.

## Applicable rights

The exact package EULA permits commercial and non-commercial distribution of complete fixed artwork in Section 2.2, with no working font or reusable font capability. Section 4.2 explicitly distinguishes editing outlined/rasterized lettering in permitted finished materials from modifying font software. Section 9 excludes permitted fixed artwork from the font software definition. The current official licensing page additionally identifies complete pre-rendered graphics inside software/hardware as permitted desktop use when no font or reusable characters are provided.

Do not ship the source OTF, the downloaded font collection, the rendering libraries, or individually reusable characters. Only the two completed static artwork files (or their high-resolution PNG equivalents) belong in the game distribution. Typography credit may identify Pricedown and Typodermic factually without implying endorsement.

The font is not public domain and this document does not relicense it. Future live/dynamic Pricedown text or embedding the font file requires separate appropriate rights. This current implementation uses completed artwork only.
